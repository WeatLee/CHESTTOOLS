# 肺部衛教互動模型

供衛教與教學使用的 3D 肺部示意模型。可旋轉、縮放，切換五肺葉配色或透明度，選擇顯示支氣管、心臟、大血管、神經與標籤。

## 使用

- 線上版：[Chesttools 肺部模型](https://weatlee.github.io/CHESTTOOLS/Tools/lung-education.html)。
- 離線版：開啟 `portable-v1.5/LungEducation.html`，或雙擊同資料夾的 `Start.cmd`。單一 HTML 檔可放隨身碟使用；建議使用近期 Chrome 或 Edge。完整解剖網格需要 WebGL 與 `DecompressionStream`，不支援網格解壓縮時會改顯示簡化肺形。

## 已有功能

- 自然外觀、五肺葉、看內部、支氣管鏡四種講解情境；肺葉透明度及主要構造可個別切換。
- 最多三處病灶。可選固定肺葉或肺段位置（右肺 10 段、左肺以 8 段合併標示）、氣管旁或隆突下位置，亦可手動點選肺表面。病灶直徑為示意比例。
- 支氣管以連續網格呈現主支、肺葉及肺段分支。支氣管鏡沿所選分支前進，並以取樣鉗或 TBNA 細針示意採樣。自由放置位置離可見支氣管太遠時不畫長距離穿刺。
- 肺段末端依肺網格內側校正，末端管徑逐漸收細，右上葉分支連接點也留出吐氣末的肺表面間距；大量胸水時，肺內支氣管與支鏡路徑會隨肺葉內縮，氣管及隆突附近保持穩定。主動脈以連續曲面呈現，消除分段網格的接縫。
- 單側或雙側胸水沿原始肺外緣顯示；大量時讓同側肺下部向肺門漸進收縮，包括上肺葉下半部。
- 呼吸起伏、合成一般呼吸音，以及可依位置切換的聽診示意。六類個人 MP3 可匯入瀏覽器本機儲存空間，網站不會接收音檔；換裝置或清除網站資料後需重新匯入。

## 適用範圍與限制

模型用於說明解剖關係與檢查流程，並非臨床影像、病人專屬解剖或器械物理模擬。胸水水位、肺葉萎陷、病灶尺寸及聽診位置均為示意。解剖網格、支氣管鏡路徑與取樣動作仍需醫師持續審核。離線單檔無法跨瀏覽器或裝置同步已匯入的個人音檔。

## 開發與發行

執行 `npm ci`、`npm test`、`npm run build`、`node package-single.mjs` 可產生隨身碟單檔版。調整支氣管中心線後先執行 `node build-airway-mesh.mjs` 重新烘焙連續網格。執行 `npm run build:web` 可產生分檔線上版，結果在 `web/`。發布時將 `web/lung-education.html` 和 `web/lung-education/` 複製到 Chesttools 的 `Tools/` 目錄。線上版先載入操作介面，再分別載入肺部、大血管及氣道網格；離線版維持單檔。

公開原始碼位於 Chesttools 的 `Tools/lung-education-src/`，只包含可公開授權的示範音檔。個人匯入音檔、私人打包版及大型原始資料集不列入公開來源。

肺部、心臟與大血管網格改作自 BodyParts3D，採 CC BY-SA 2.1 JP；介面使用 Three.js（MIT）。其他聲音來源與授權列於 `THIRD_PARTY_NOTICES.txt` 及頁面中的「聽診音來源與授權」。個人匯入音檔不包含在公開版本內。
